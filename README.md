# 深渊试炼 · Abyss Trial

**实时 2D 俯视角 Roguelike 动作游戏**。WASD 走位躲避弹幕与近战，自动射击最近的敌人，
杀掉一波 → 处理战利品 → 三选一强化 → 迎接下一波，直到倒下。

纯前端、零依赖、零构建，双击 `index.html` 即可游玩。

## 玩法

- **移动**：`WASD` / 方向键 8 方向移动；竞技场有 4 根柱子可做掩体（阻挡弹幕与走位）
- **攻击**：自动向射程内（300px）最近的敌人射击，每 0.7s 一箭，玩家专注走位
- **受击无敌帧**：挨打后有 0.7s 无敌时间（角色闪烁），是躲避弹幕的核心窗口
- **敌人分两种**：
  - **近战**：追击玩家，接触后近身攻击（每 1.15s 一次）
  - **远程**：与玩家保持 190~280px 距离带、侧向环绕，每 2.2s 朝玩家发射弹幕（可走位躲避）
  - **BOSS**（每 5 波）：缓慢追击 + 每 2.6s 扇形 3 连弹幕
- **多敌人小队**：第 1 波 1 个敌人，之后每 4 波多一个（最多 4 个）；多敌人时**总血量/总攻击 ≈ 单怪**（均摊），普通波首个敌人是精英
- **升级**：每波胜利后固定三张属性卡（生命 / 攻击 / 防御各一张），稀有度独立随机
- **战利品**：击杀后所有敌人身上的装备都会掉落，逐件决定去留；全部处理完才能选属性卡
  - 空槽位 → 直接装备；同款 → **吸收强化**（Lv+1，满 Lv.5 后升华稀有度）；不同款 → 可**替换**
- **装备**：4 部位（武器 / 护甲 / 头盔 / 饰品）× 3 件，五档稀有度；怪物装备等级每 6 波 +1

### 敌人词缀（实时行为版）

从第 3 波起每 2 波敌人普遍带一个词缀，按位置固定轮换、可预判。双刃剑设计：

| 词缀 | 强化 | 弱点 |
| --- | --- | --- |
| 🛡️ 重甲 | 防御 ×1.8 | 生命 −20% |
| ⚡ 迅捷 | 移速 +45% | 生命 −25% |
| 🔥 狂怒 | 血量越低攻击越高（最高 +80%） | 防御 −40% |
| 🌿 再生 | 每 3 秒回复 8% 生命 | 攻击 −30% |
| 🦔 尖刺 | 被命中反弹 3 点伤害 | 防御 −40% |

带词缀的敌人掉落物稀有度 +1。真 BOSS 不带词缀。

### 场景事件

每隔 3 波（从第 3 波起）触发选择式事件，按波次确定性轮换：🕯️ 祭坛 / 🔀 歧路 / 🎭 商人 / 💧 泉水。

### 无随机战斗

战斗结算**没有任何概率判定**：伤害恒定（攻 − 防，破甲/减伤折算）、暴击是固定节拍
（「每第 N 箭必定 ×M」）、狂怒按血量曲线。随机只留在非战斗环节（卡牌稀有度、怪物装备款式、名字）。

快捷键：`R` 重开。弹窗（选卡 / 事件 / 结算）打开时游戏自动暂停。

## 目录结构

```
index.html                 页面骨架：顶栏、画布、弹窗
css/
  base.css                 重置、主题底色、背景层
  overlay.css              升级三选一、战利品、结算、事件弹窗（复用）
  arena.css                顶栏、竞技场画布、提示条
js/
  core/
    config.js              所有数值：玩家/敌人参数、成长曲线、装备定义、词库
    utils.js               工具 + 向量/几何（碰撞）
    audio.js               WebAudio 实时合成音效
    engine.js              固定时间步长主循环 + 键盘输入（逻辑与渲染分离）
  game/
    state.js               全局状态与实体工厂
    equipment.js           装备实例、属性聚合、战力重算
    combat.js              实时伤害结算：防御/破甲/减伤/护盾/吸血/反伤/流血/无敌帧
    bullets.js             双方弹幕：发射、飞行、碰撞（命中触发流血）
    player.js              WASD 移动、柱子碰撞、自动射击
    enemies.js             敌人 AI：近战追击 / 远程保持距离带+环绕 / BOSS 扇形弹幕
    waves.js               波次编成：数量曲线、精英/BOSS、敌人装备、词缀确定性分配
    loot.js                战利品：逐件判定 装备 / 吸收强化 / 升华 / 替换 / 放弃
    cards.js               纯属性三选一卡池与交互
    events.js              场景事件（弹窗期间暂停）
    flow.js                流程状态机：play → busy → upgrade → event → 下一波 / over
  ui/
    ui.js                  DOM 引用、顶栏同步、装备行、结算弹窗
  render/
    render.js              Canvas 2D 绘制：竞技场、实体、弹幕、飘字、横幅
  main.js                  初始化与启动（最后加载）
scripts/
  test.js                  无头测试：功能断言 + 平衡模拟（node scripts/test.js [--sim N]）
```

模块全部挂到 `window.ABYSS` 命名空间，靠 `<script>` 顺序解决依赖，无打包器，
`file://` 直接打开也不会被 ES Module 的 CORS 策略拦住。逻辑层（core/game）不碰 DOM/canvas，
可在无头环境测试；渲染层（ui/render）只读状态。

## 调整数值

改 `js/core/config.js` 一处即可：`player`（移速/射速/无敌帧）、`melee/ranged/boss`（敌人行为参数）、
`mon`（成长曲线）、`squad`（小队均摊）、`events/affixes`（节奏）、`forge`（装备等级上限）。
装备词条在 `ITEM_DEFS` 里。

## 平衡基线

用真实游戏代码跑无头模拟（人类化 bot：0.28s 反应延迟、6% 走位失误、战利品全收、攻击卡优先）：

| 指标 | 结果（30 局） |
| --- | --- |
| 中位波数 | 13 |
| p10 / p90 | 7 / 30 |
| 平均 | 17.0 |

改完数值建议 `node scripts/test.js --sim 30` 复测，确认中位落在 12~18 波区间。
调平衡的杠杆优先级：`mon.hpK`（血量曲线）→ 敌人移速/弹幕速度 → `player.iframes`（容错）。

## 部署

线上地址：<https://game.cat21432961.online>

部署形态与 `mailhub` / `book` 一致：**Cloudflare Workers**（静态资源 Worker），
Worker 名 `game`，自定义域名由 `wrangler.toml` 的 `[[routes]]`（`custom_domain = true`）托管。

```bash
bash scripts/deploy.sh        # 生成 dist/ → 给资源加版本指纹 → wrangler deploy
```

首次在新机器部署需先 `npx wrangler login` 授权。
