# 深渊试炼 · Abyss Trial

**实时 2D 俯视角 Roguelike 生存游戏**。WASD 走位躲避弹幕与近战，自动射击（带预判提前量），
敌人源源不断涌来，每分钟出现一只精英，击杀精英获取装备宝箱，升级强化攻击方式，解锁新地图，直到倒下。

纯前端、零依赖、零构建，双击 `index.html` 即可游玩。

## 玩法

- **移动**：`WASD` / 方向键 8 方向移动；大世界 2000×1400，相机跟随，右下角小地图
- **攻击**：自动射击射程内（基础 320px，可升级）最近的敌人，带**预判提前量**（打移动靶）；每 0.8s 一箭
- **源源不断的敌人**：无波次概念，敌人按时间间隔持续在玩家周围 380~680px 环带刷新；
  场上存活上限与刷怪频率随分钟阶段逐步增长
- **分钟精英**：每 60 秒出现一只精英怪（必带词缀、生命 ×2.4），**击杀后原地掉落装备宝箱**；
  每 5 分钟为首领（扇形弹幕、无词缀）
- **宝箱**：📦 精英掉落 + 开局引导宝箱，走近自动开启，开出 1~2 件装备——**装备的唯一来源**
  逐件决定去留：空槽装备 / 同款强化（满级升华）/ 不同款替换
- **经验升级**：击杀敌人获得经验，经验满**自动升级**（需求逐层递增：二次曲线）。
  **升级不再自动成长三维**——属性提升只来自升级选卡与装备；升级回复 22% 生命
  - 普通等级 → **属性三选一**（生命/攻击/防御，五档稀有度，数值有分量）
  - **每 10 级** → **攻击方式三选一**（攻速/散射/贯穿/射程/飞刃/暴击/弹速/吸血/减速/护盾）
- **事件地点**：紫色光圈标记的一次性地点（🕯️ 祭坛 / 🔀 歧路 / 🎭 商人 / 💧 泉水），
  走近触发选择弹窗，选择后地点消失；刷新稀疏（间隔 40s、场上最多 2 个）
- **陷阱**：选择事件选项后有 **35% 概率**触发陷阱（🪤）：
  - **血肉盛宴**：45 秒内刷新的敌人生命 ×2
  - **狂怒低语**：45 秒内刷新的敌人攻击 +25%
  - **伏击**：立即召唤 3 只敌人围攻
- **受击无敌帧**：挨打后 0.8s 无敌时间（角色闪烁），躲避弹幕的核心窗口
- **敌人**：
  - **近战**（移速 136，接近玩家上限）：追击贴身攻击
  - **远程**（移速 82）：保持 200~320 距离带、侧向环绕、发射弹幕；距离过远会**冲刺追击**（防止风筝死锁）
- **动态障碍物**：柱子随主角移动在周围随机生成（上限 16 根）、远离后自动移除——可做掩体挡弹幕
- **多地图**：每 3 级解锁一张新地图（4 级即解锁第二张：深渊洞窟 → 荒芜骨林 → 熔岩裂隙 → 虚空回廊 → 腐雾沼泽），
  换主题配色 + 重新随机障碍布局，敌人 hp/atk 每图 +12%

### 升级卡池

**普通等级 · 属性三选一**（稀有度越高数值越大）：❤ 生命 +28~198 / ⚔ 攻击 +9~44 / 🛡 防御 +3~14

**每 10 级 · 攻击方式三选一**：

| 卡 | 效果 | 上限 |
| --- | --- | --- |
| ⚡ 攻速提升 | 射击间隔 −18% | 乘算下限 0.35 |
| 🏹 散射箭 | 每次射击多 1 支箭（扇形散开） | 4 支 |
| 🎯 贯穿箭 | 箭矢穿透 1 个额外敌人 | 3 |
| 📡 射程提升 | 攻击射程 +15%（索敌与箭矢飞行距离同步） | ×2.0 |
| 🌀 环绕飞刃 | +2 枚绕身飞刃，持续切割 | 6 枚 |
| 💥 暴击节奏 | 每第 4 发必定暴击 ×2.2，每层节拍提前且倍率 +0.1 | 每 2 发 |
| 💨 弹速提升 | 箭矢飞行速度 +18%（命中更快） | ×1.8 |
| 🩸 吸血箭 | 箭矢伤害的 6% 转化为治疗 | 24% |
| 🕸️ 减速箭 | 命中减速 18%，持续 1.6s | 3 层（−54%） |
| 🔵 护盾生成 | 每 8s 获得 10 点护盾，每层节拍提前且 +4 | 每 3s / 26 点 |

### 敌人词缀（实时行为版）

普通敌人从第 3 分钟起每 2 分钟普遍带一个词缀，按位置固定轮换、可预判；精英必带一个。双刃剑设计：

| 词缀 | 强化 | 弱点 |
| --- | --- | --- |
| 🛡️ 重甲 | 防御 ×1.8 | 生命 −20% |
| ⚡ 迅捷 | 移速 +45% | 生命 −25% |
| 🔥 狂怒 | 血量越低攻击越高（最高 +80%） | 防御 −40% |
| 🌿 再生 | 每 3 秒回复 8% 生命 | 攻击 −30% |
| 🦔 尖刺 | 被命中反弹 3 点伤害 | 防御 −40% |

首领（每 5 分钟）不带词缀。

### 场景事件（地点触发）

事件是地图上的**特定地点**：紫色光圈 + 图标，小地图上有紫点。
走近（44px 内）触发，一次性，选择后消失。四种按刷新顺序轮换：🕯️ 祭坛 / 🔀 歧路 / 🎭 商人 / 💧 泉水。
**但小心陷阱**——每次选择都有 35% 概率触发 🪤 陷阱。

### 无随机战斗

战斗结算**没有任何概率判定**：伤害恒定（攻 − 防，破甲/减伤折算）、暴击是固定节拍、狂怒按血量曲线。
随机只留在非战斗环节（卡牌稀有度、升级抽卡、宝箱装备款式、陷阱触发、名字、刷新位置）。

## 开发

- 架构：`js/core`（config / utils / audio / engine 固定时间步长循环）→ `js/game`（纯逻辑，
  不碰 DOM/canvas）→ `js/render`（Canvas 只读渲染）+ `js/ui`（DOM/HUD）
- 测试：`node scripts/test.js`（无头功能测试）；`node scripts/test.js --sim 25`（人类化 bot 平衡模拟）
- 真浏览器验证：`node scripts/cdp_v9_test.js`（CDP 驱动 headless Chrome，验证卡池分流/陷阱/新卡链路）
- 调平衡只改 `js/core/config.js`
