# 深渊试炼 · Abyss Trial

**实时 2D 俯视角 Roguelike 动作游戏**。WASD 走位躲避弹幕与近战，自动射击（带预判提前量），
击杀获得经验，升级强化攻击方式，解锁新地图，直到倒下。

纯前端、零依赖、零构建，双击 `index.html` 即可游玩。

## 玩法

- **移动**：`WASD` / 方向键 8 方向移动；大世界 2000×1400，相机跟随，右下角小地图
- **攻击**：自动射击射程内（320px）最近的敌人，带**预判提前量**（打移动靶）；每 0.7s 一箭
- **经验升级**：击杀敌人获得经验，经验满**自动升级**：
  - 三维属性自动成长（+14 生命 / +3 攻击 / +1 防御）并回复 30% 生命
  - 每级弹出**升级三选一**（战斗暂停），选项见下表
- **受击无敌帧**：挨打后 0.8s 无敌时间（角色闪烁），躲避弹幕的核心窗口
- **敌人**：
  - **近战**（移速 136，接近玩家上限）：追击贴身攻击
  - **远程**（移速 82）：保持 200~320 距离带、侧向环绕、发射弹幕；距离过远会**冲刺追击**（防止风筝死锁）
  - **BOSS**（每 5 波）：缓慢追击 + 扇形 3 连弹幕
- **敌人随机出现**：每波敌人在玩家周围 380~680px 环带随机刷新
- **数量曲线**：第 4 波起每 3 波 +1 个敌人（上限 5 个），多敌人时总强度 ≈ 单怪（均摊）；普通波首个敌人是精英
- **动态障碍物**：柱子随主角移动在周围随机生成（上限 16 根）、远离后自动移除——可做掩体挡弹幕
- **战利品**：波次全灭后掉落敌人全部装备，逐件决定去留（同款强化 / 不同款替换），处理完「继续探索」
- **多地图**：每 4 级解锁一张新地图（深渊洞窟 → 荒芜骨林 → 熔岩裂隙 → 虚空回廊 → 腐雾沼泽），
  换主题配色 + 重新随机障碍布局，敌人 hp/atk 每图 +12%

### 升级卡池（每级三选一）

| 卡 | 类型 | 效果 | 上限 |
| --- | --- | --- | --- |
| ⚡ 攻速提升 | 攻击方式 | 射击间隔 −18% | 乘算下限 0.35 |
| 🏹 散射箭 | 攻击方式 | 每次射击多 1 支箭（扇形散开） | 4 支 |
| 🎯 贯穿箭 | 攻击方式 | 箭矢穿透 1 个额外敌人 | 3 |
| 🧲 追踪箭 | 攻击方式 | 箭矢自动弯向最近敌人 | 2 |
| 🌀 环绕飞刃 | 攻击方式 | +2 枚绕身飞刃，持续切割 | 6 枚 |
| ❤ / ⚔ / 🛡 | 属性 | 五档稀有度，同旧版 | 无 |

### 敌人词缀（实时行为版）

从第 3 波起每 2 波敌人普遍带一个词缀，按位置固定轮换、可预判。双刃剑设计：

| 词缀 | 强化 | 弱点 |
| --- | --- | --- |
| 🛡️ 重甲 | 防御 ×1.8 | 生命 −20% |
| ⚡ 迅捷 | 移速 +45% | 生命 −25% |
| 🔥 狂怒 | 血量越低攻击越高（最高 +80%） | 防御 −40% |
| 🌿 再生 | 每 3 秒回复 8% 生命 | 攻击 −30% |
| 🦔 尖刺 | 被命中反弹 3 点伤害 | 防御 −40% |

带词缀的敌人掉落物稀有度 +1。真 BOSS 不带词缀。

### 场景事件

每隔 3 波（从第 3 波起）触发选择式事件，按波次确定性轮换：🕯️ 祭坛 / 🔀 歧路 / 🎭 商人 / 💧 泉水。

### 无随机战斗

战斗结算**没有任何概率判定**：伤害恒定（攻 − 防，破甲/减伤折算）、暴击是固定节拍、狂怒按血量曲线。
随机只留在非战斗环节（卡牌稀有度、怪物装备款式、名字、刷新位置）。

快捷键：`R` 重开。弹窗（升级 / 战利品 / 事件 / 结算）打开时游戏自动暂停。

## 目录结构

```
index.html                 页面骨架：顶栏（等级/经验条）、画布、弹窗
css/
  base.css                 重置、主题底色、背景层
  overlay.css              升级三选一、战利品、结算、事件弹窗
  arena.css                顶栏、竞技场画布、等级/经验条样式
js/
  core/
    config.js              所有数值：世界尺寸、经验曲线、地图主题、敌人参数、装备定义
    utils.js               工具 + 向量/几何（碰撞）
    audio.js               WebAudio 实时合成音效
    engine.js              固定时间步长主循环 + 键盘输入
  game/
    state.js               状态、实体工厂、动态障碍物生成/移除
    equipment.js           装备实例、属性聚合、战力重算
    combat.js              伤害结算 + 经验/升级（自动成长、里程碑地图解锁）
    bullets.js             双方弹幕：贯穿、追踪转向、碰撞
    player.js              WASD 移动、散射 volley（预判提前量）、环绕飞刃
    enemies.js             AI：近战追击 / 远程距离带+冲刺追击 / BOSS 扇形弹幕
    waves.js               波次编成：随机刷新点、经验值、词缀分配、地图增幅
    loot.js                波次战利品：逐件判定 + 「继续探索」
    cards.js               升级三选一卡池（攻速/攻击方式/属性）
    events.js              场景事件
    flow.js                流程状态机：升级队列、地图切换、动态障碍计时
  ui/
    ui.js                  DOM 引用、顶栏（等级/经验/装备）同步、结算弹窗
  render/
    render.js              Canvas 绘制：相机跟随、地图主题、小地图、飞刃
  main.js                  初始化与启动
scripts/
  test.js                  无头测试：49 项功能断言 + 平衡模拟（node scripts/test.js [--sim N]）
```

模块全部挂到 `window.ABYSS` 命名空间，靠 `<script>` 顺序解决依赖，无打包器。
逻辑层（core/game）不碰 DOM/canvas，可无头测试；渲染层只读状态。

## 调整数值

改 `js/core/config.js` 一处即可：`player`（移速/射速/无敌帧）、`xp/growth`（经验曲线/每级成长）、
`maps.milestoneEvery`（地图解锁节奏）、`obstacles`（动态障碍参数）、`melee/ranged/boss`（敌人行为）、
`mon`（成长曲线 + `mapBoost` 每图增幅）、`squad`（数量曲线）。

## 平衡基线

用真实游戏代码跑无头模拟（人类化 bot：0.28s 反应延迟、4% 走位失误、升级卡优先攻击方式、战利品全收）：

| 指标 | 结果（30 局） |
| --- | --- |
| 波次 中位 / p10 / p90 | 11 / 7 / 22 |
| 等级 中位 | 11 |
| 解锁地图 中位 / 最多 | 3 / 5 |

> 调平衡时踩过的两个**风筝死锁**（模拟暴露）：
> 1. 远程怪追不上玩家 → 距离带外**冲刺追击**（×2.6 速度）；
> 2. 环绕中的远程怪打不中（箭矢打当前位置，弹丸飞行期间目标已侧移）→ 玩家射击带**预判提前量**。
> 这两个修复对真人手感同样关键，改移动相关数值后务必复测。

## 部署

线上地址：<https://game.cat21432961.online>

部署形态与 `mailhub` / `book` 一致：**Cloudflare Workers**（静态资源 Worker），
Worker 名 `game`，自定义域名由 `wrangler.toml` 的 `[[routes]]`（`custom_domain = true`）托管。

```bash
bash scripts/deploy.sh        # 生成 dist/ → 给资源加版本指纹 → wrangler deploy
```
